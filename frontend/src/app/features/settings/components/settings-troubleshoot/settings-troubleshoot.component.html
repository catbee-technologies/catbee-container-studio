Restores all CatBee configuration, resource limits, and Docker daemon settings to default values. Your containers and images are preserved.

Factory Reset & Teardown

Destructive

Removes the CatBee-managed Kubernetes cluster on the active engine, the built-in engine and its data, CatBee CLI contexts, PATH entries, and directories. Other engines and clusters are preserved. Recommended before removing the application or moving it to Trash.
